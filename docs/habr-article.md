## Зачем это вообще

Задача из универа: для каждой лабы собрать docx-отчет. В нем условие каждой задачи,
скриншот решения со Stepik и подпись «Рисунок 2.N». За семестр это около 400 итераций:
открыл окно, скопировал текст, свернул, вставил в ворд, снова открыл окно, сделал
скриншот ножницами... Проект начинался как знакомство с пакетным менеджером uv, а
закончился программой, которая делает это за меня.

## Что получилось

[stepik-report-creator](https://github.com/viteax/stepik-report-creator): запускаешь
`uv run main.py 7` и получаешь готовый docx по 7-й лабе.

- условия и решения берутся через API Stepik;
- в отчет попадает последнее правильное решение (`correct`);
- код рисуется картинкой через Pillow, шрифт — JetBrains Mono;
- для каждого раздела можно подложить свой шаблон `assets/<номер>-template.docx`;
- в конце программа печатает число задач и время работы.

## Как получить доступ к API

Нужно создать приложение на https://stepik.org/oauth2/applications/ с настройками
`confidential` и `client-credentials`, а `client_id` и `client_secret` положить в `.env`.
Токен программа получает сама запросом на `/oauth2/token/` с `grant_type=client_credentials`.

## Как устроено внутри

1. По номеру раздела берем `sections` курса и находим нужный.
2. Для каждого `unit` получаем урок, для каждого шага — его содержимое.
3. Шаги типа `code` разбираем: заголовок задачи из `<h2>`, условие — абзацы до
   «Формат входных данных».
4. Решение берем из `/api/submissions?step=<id>`: идем с конца списка и берем первую
   попытку со статусом `correct`.
5. Код превращается в картинку, а `python-docx` собирает документ по шаблону.

## Запуск

```bash
pip install uv
git clone https://github.com/viteax/stepik-report-creator.git
cd stepik-report-creator
uv sync
cp .env.example .env   # вписать CLIENT_ID и CLIENT_SECRET
uv run main.py 7
```

## Сколько это занимает

Вручную: в среднем около 2 часов на один отчет. Программой: около 2 секунд на реальных данных
(`uv run main.py 7`). Время почти целиком зависит от запросов к API: на каждую задачу их несколько.

## Ограничения

- нужен свой OAuth-ключ Stepik;
- обрабатываются только задачи с кодом;
- оформление заточено под один формат отчета, остальное правится в `clients/word.py`;
- условие извлекается эвристикой и может поехать на нестандартной верстке.
